HU-3.3 / T-3.3.1 - Tabla del registro de auditoria en PostgreSQL (titulos_db)

Hibernate (ddl-auto=update) crea la tabla eventos_auditoria a partir de la
entidad EventoAuditoria. La columna 'accion' queda con un CHECK que la limita a
la lista cerrada del enum AccionAuditoria (enum en Java + restriccion en la BD).

psql> \d eventos_auditoria

                                   Table "public.eventos_auditoria"
   Column   |              Type              | Nullable |             Default
------------+--------------------------------+----------+----------------------------------
 id         | bigint                         | not null | generated by default as identity
 accion     | character varying(20)          | not null |
 detalle    | character varying(500)         | not null |
 fecha_hora | timestamp(6) without time zone | not null |
 titulo_id  | bigint                         | not null |
 usuario    | character varying(50)          | not null |
Indexes:
    "eventos_auditoria_pkey" PRIMARY KEY, btree (id)
Check constraints:
    "eventos_auditoria_accion_check" CHECK (accion IN ('REGISTRAR','APROBAR','RECHAZAR'))
